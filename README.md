## Pre-Setup: Enable Sideloading

Before installing any IPTV app, you need to allow apps from unknown sources:

1. From Firestick home, go to **Settings → My Fire TV → Developer Options**
2. If "Developer Options" is hidden, go to **About → Fire TV Stick** and click 7 times on the build number to unlock it
3. Turn ON **Apps from Unknown Sources**
4. (Optional but recommended) Turn ON **ADB Debugging**

That's it. Your Firestick can now sideload apps.

## Step-by-Step: Installing TiviMate

The fastest method uses the **Downloader** app from the Amazon Appstore:

1. Open **Find → Search** on Firestick home
2. Type **"Downloader"** and install the app by AFTVnews
3. Open Downloader → enter URL: `https://tivimate.com/get`
4. Click **Go** → wait for the APK to download
5. Click **Install** → **Open**
6. Enter your IPTV provider's **M3U URL** or **Xtream Codes login**
7. (Optional) Add EPG XMLTV URL for the program guide
8. Done — start watching

**Pro tip:** Pin TiviMate to your Firestick home row for one-click access.

## Troubleshooting

**Problem: Constant buffering**
- Run a **speed test** on Firestick (use the Analiti app)
- Below 25 Mbps? Upgrade your router or move it closer to the Firestick
- Above 50 Mbps but still buffering? Try a different IPTV app or contact provider
- **Restart your Firestick weekly** — Fire OS leaks RAM

**Problem: Black screen on channel start**
- Codec mismatch — go to TiviMate Settings → Playback → set decoder to **Software**
- Some channels use HEVC; older Firesticks struggle. Upgrade to 4K Max if persistent.

**Problem: App crashes on launch**
- Clear app cache: **Settings → Applications → Manage Installed Apps → [App] → Clear Cache**
- If still crashing, uninstall and reinstall

**Problem: EPG not loading**
- Verify your XMLTV URL works in a browser
- TiviMate: Settings → Playlists → EPG → Force Update
